# 🌐 Personal Developer Portfolio | Lalita Bhoi

Welcome to my personal developer portfolio website! This project showcases my skills, academic background, achievements, and software development projects.

🚀 **Live Demo:** [lalitabhoi-21.github.io/lalita-portfolio](https://lalitabhoi-21.github.io/lalita-portfolio/)

---

## ✨ Features
* 📱 **Fully Responsive:** Smooth layout designed for Desktop, Tablet, and Mobile screens.
* 🎨 **Modern Dark Theme:** Designed with glowing UI elements and polished CSS styling.
* ⚡ **Fast Performance:** Built with React and Vite for super-fast loading and smooth performance.
* 📑 **Interactive Sections:** Hero Section, About Me, Technical Skills, Featured Projects, Education, and Contact.

---

## 🛠️ Tech Stack & Libraries
* **Frontend:** React.js, Tailwind CSS
* **Icons:** Lucide React
* **Build Tool:** Vite
* **Deployment:** GitHub Pages
